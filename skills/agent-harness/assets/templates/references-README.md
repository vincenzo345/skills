# Calibration references

Drop 3–6 examples here that anchor the Evaluator's taste. This is the single highest-leverage thing
you can do to raise output quality — it converts "make it good" into "make it look/behave like THIS".

- GOOD examples: screenshots, sample outputs, or reference artifacts you want the result to resemble.
- BAD examples (name them `bad-*`): 1–2 counter-examples of what to avoid. The Evaluator is told to
  grade against both.

The rubric (`.harness/rubric.md`) can point at specific filenames here. Keep files small (< 1 MB).
