# Workbench adherence conformance cases

These cases capture the observable agent behavior expected at the user-message and persisted-state seam. They are regression oracles for forward model evaluations; the repository test validates their completeness and internal consistency but does not invoke a model or claim behavioral compliance by itself.

Each case identifies the triggering stimulus, relevant preconditions, required and forbidden actions, and the externally observable result. Expected behavior is independent of exact response wording.
