# Workbench evidence guards — outcome frame

The item implements exactly three controls:

1. Findings carry `fact`, `measurement`, `hypothesis`, or `inference`; only sourced facts and measurements project as established evidence. Legacy string findings remain readable but non-established.
2. A dependency-free Claude `PreToolUse` hook blocks the first investigative tool in a Workbench diagnosis until `diagnosing-bugs` has been invoked for the current user request.
3. Two behavior-oracle cases preserve code-derived theories as hypotheses and require a discriminating intervention before a measured bottleneck is called the root cause.

The predecessor hardening item and all manual-extraction items stay frozen. General Stop hooks, broad lifecycle hooks, causal-proof frameworks, LLM reviewers, commits, deployment, publication, and closure are excluded.

Completion requires focused tests for each public seam plus repository validation. The comparison catalog remains a contract fixture, not proof that a model was executed.
