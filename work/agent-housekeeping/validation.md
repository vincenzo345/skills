Observed on Windows through Codex subagents using inherited model/settings (the runtime does not expose an exact model revision). Replay agents received concrete tasks, not pass/fail rubrics. The evaluator inspected resulting files and ran retained tests independently. All counts below exclude evaluator fixture preparation and inspection; a tool call is one functions.exec call and these task calls each invoked one shell command unless noted.
