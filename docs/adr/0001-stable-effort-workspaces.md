# Keep each effort in a stable workspace

Use one visible, request-named workspace per effort across discovery, Wayfinder decisions, specification, and implementation issues. Keep completed efforts at their original locations and exclude them from the active queue; retain superseded artifacts separately within the effort.

Vince accepted this recommended design after comparing stable folders with physical active/archive separation. Stable paths reduce broken references and let later sessions resume the same work. Explicit readiness and queue membership distinguish actionable work from history. Decision tickets and implementation issues remain separate, and a configured remote issue tracker retains authority over remote issue state.

The alternative of moving completed folders offers a cleaner file-explorer split but requires link maintenance. Stage-first and session-first layouts fragment the context needed by downstream skills.
